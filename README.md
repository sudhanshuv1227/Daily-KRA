# Daily KRA React Lab

The Day 1 and Day 2 learning projects are now one Vite React application.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. Use the sidebar to switch between the JavaScript Core lesson and the React product catalog.

## Lessons

- Day 1: execution context, function forms, hoisting, and lexical scope
- Day 2: `useState`, props, props drilling, `useEffect`, external fetching, filters, and cart state
